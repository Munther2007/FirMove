# سينما كلاود – خطوات التشغيل

## 1) قاعدة البيانات (دقيقتان)
1. ادخل مشروعك في Supabase ثم **SQL Editor** ثم **New query**.
2. الصق محتوى ملف `setup.sql` كاملًا واضغط **Run**.
3. من **Project Settings ثم API** انسخ `Project URL` و `anon public` والصقهما في `config.js`.
   لا تضع مفتاح `service_role` في الموقع أبدًا.

## المدير (Admin)
1. أنشئ حسابك من الموقع.
2. في SQL Editor شغّل: `insert into public.admins (user_id) select id from auth.users where email = 'بريدك';`
3. سجّل الخروج وادخل من جديد، فيظهر زر **لوحة المدير**: إحصائيات، قائمة الأعمال والمستخدمين، وحذف أي عمل.

## القائمة الجانبية والإعدادات
- زر ☰ يفتح القائمة: الرئيسية، مسلسلات، أفلام، مقاطع قصيرة، قرآن، التواصل معنا، الملف الشخصي، تسجيل الدخول والخروج.
- المدير يرى أيضًا **لوحة المدير** و**الإعدادات**، وفيها رقم التواصل ورقم الواتساب ورابط التليجرام، وتظهر لكل الزوار في «التواصل معنا».
- عند رفع عمل اختر نوعه: فيلم، مسلسل، مقطع قصير، أو قرآن.

## وضع التجربة المحلي
بدون تعبئة config.js يعمل الموقع بحسابات محلية داخل المتصفح (أول حساب يصبح مديرًا تلقائيًا). للتجربة فقط، ولا يصلح للنشر العلني.

## 2) إعدادات الحسابات (مهم لـ 500 مستخدم)
- **Authentication ثم Providers ثم Email**: عطّل **Confirm email**، لأن البريد المدمج في Supabase يرسل عددًا قليلًا جدًا من الرسائل في الساعة، وسيتعطل التسجيل مع الزحام.
  وإن أردت التأكيد بالبريد فاربط خدمة SMTP (مثل Resend أو Brevo).
- **Authentication ثم URL Configuration**: ضع رابط موقعك على GitHub Pages في Site URL.

## 3) الرفع على GitHub Pages
1. ارفع الملفات (`index.html` و `config.js`) إلى مستودع جديد.
2. **Settings ثم Pages**: Branch = main و Folder = root ثم Save.
3. افتح الرابط `https://USERNAME.github.io/REPO/` من المتصفح، ولا تفتح الملف من الجوال مباشرة.

## 4) السعة
- الصفحات والحسابات وقاعدة البيانات تتحمل 500 مستخدم متزامن بسهولة.
- **عنق الزجاجة هو عرض الفيديو (Bandwidth)**: كل مشاهدة تستهلك من باقة النقل. الباقة المجانية (حوالي 5 جيجابايت شهريًا، وحد 50 ميجابايت للملف) لا تكفي لهذا العدد.
  لـ 500 متزامن استخدم باقة **Supabase Pro**، أو استضف ملفات الفيديو على Cloudflare R2 أو Bunny ثم ضع روابطها.
- الموقع يحمّل بيانات الفيديو عند الضغط فقط (`preload=metadata`) ويعرض آخر 300 عمل لتخفيف الحمل.

## التنزيل
- زر تنزيل لكل فيلم أو حلقة، وزر لتنزيل المسلسل كاملًا.
- المسلسل يُجمع من الحلقات التي لها نفس العنوان بالضبط.

ارفع محتوى تملك حقوقه فقط.
